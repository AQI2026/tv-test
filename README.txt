【TV能力检测 v0.2】

这个版本不是正式软件，只是一个"体检工具"，用来检查你的电视允许我们做哪些事：
悬浮窗遮罩、无障碍服务、开机自启、局域网通信。

一、更新到 GitHub（沿用上次的仓库）
1. 解压本压缩包。
2. 进入你的仓库，点 "Add file" → "Upload files"，
   把解压出来的【所有内容】拖进去（同名文件会被覆盖），点 "Commit changes"。
3. 点 Actions → 左边 "Build APK" → 最新一次运行，等绿色对勾，
   在页面底部 Artifacts 里下载 apk，解压后用 app-release.apk。
   （没有自动运行的话，点 Run workflow 手动运行。）
注意：这个版本的包名与上次不同，会和上次的测试App并存，不需要卸载旧的。

二、在电视上依次测试，并记录结果
1. 安装并打开"TV能力检测"，看屏幕上的状态信息。
2. 点"1 授予悬浮窗权限"，开启后返回。
3. 点"2 打开无障碍设置"，找到"TV能力检测"并开启。
   找不到入口，请记下按钮后屏幕下方事件记录里的提示。
4. 点"3 启动守护服务"。
5. 手机浏览器输入屏幕上显示的"电视局域网地址:8765"（例如 http://192.168.1.20:8765），
   看能不能打开。请分别在"手机连电视所在的路由器"和"手机连另一个路由器"两种情况下各试一次。
6. 点"4 …（悬浮窗方式）"，10秒内按遥控器切换到 HDMI 信号源（或回到桌面、打开爱奇艺），
   看黑色遮罩有没有盖住画面；再试按遥控器各个键，看能不能关掉它。
7. 点"5 …（无障碍方式）"，做同样的操作。
8. 点"6 …回主页测试"，在 5 秒内随便打开别的应用，看是不是被强制拉回主页。
9. 开机测试：拔掉电视电源，等十几秒再插上开机，
   看 App 有没有自动出现；再打开 App 看"收到开机广播次数"有没有增加。
10. 待机测试：用遥控器关机（待机），再开机，看事件记录里有没有"SCREEN_OFF / SCREEN_ON"。

三、把结果告诉我
把屏幕上的状态文字和事件记录拍照或截图发给我。
手机浏览器打开电视地址的页面里也有完整记录，可以直接复制发给我。
如果打包失败（红叉），把红色的报错文字复制给我。
